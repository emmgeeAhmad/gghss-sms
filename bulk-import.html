Bulk Import Students

Paste CSV data below — same format as the school's admission register export:
AdmissionNo,RollNo,Name,FatherName,MotherName,DOB,Address,Class,Section,Subjects

• DOB should be DD-MM-YYYY (or leave blank if unknown)
• Subjects only matters for Class 11/12 — comma-separated inside quotes if it contains commas, e.g. "English, Physics, Chemistry, Biology, EVS". Leave blank for Class 9/10.
• Students already in the system (matched by Admission No.) are automatically detected and skipped — safe to paste the same list twice.
• Works entirely against your live database — this connects directly to the same shared data the main app uses.
