GGHSS Singhpora Kalan — Bulk Student Import

Log in, pick your CSV files, review, import. Writes straight to the same database as the main app.

1. Log in

Use the same username & password you use in the main app (needs office/admissions access).

2. Choose CSV file(s)

Pick one or more CSV files (you can select all three class files at once on most phones — tap the field, then long-press / use "select multiple" in your file picker). Each file must start with a header row like AdmissionNo,RollNo,Name,FatherName,MotherName,DOB,Address,Class,Section,Subjects.
